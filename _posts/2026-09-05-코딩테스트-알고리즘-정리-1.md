코딩테스트에서 자주 사용하는 알고리즘을 **Python**으로 정리했다.

## 자주 쓰는 준비 코드

```python
import sys
from collections import deque
from bisect import bisect_left, bisect_right

input = sys.stdin.readline # input()과 같지만 더 빠르다!
```

- `deque`: BFS의 큐, 양방향 삽입·삭제
- `bisect`: 정렬된 배열의 이분 탐색
- `set`, `dict`: 평균 `O(1)` 탐색
- `heapq`: 우선순위 큐가 필요할 때 사용

## 1. 브루트포스(완전 탐색)

가능한 모든 경우를 직접 확인한다. 입력 크기가 작거나 경우의 수가 충분히 적을 때 가장 먼저 고려한다.

- 핵심: **전체 경우의 수 × 한 경우를 검사하는 비용** 계산
- 자주 쓰는 도구: 반복문, `itertools.product`, `permutations`, `combinations`
- 중간에 답이 확정되면 즉시 종료한다.

```python
# 합이 target인 서로 다른 두 수 찾기: O(N^2)
for i in range(n):
    for j in range(i + 1, n):
        if nums[i] + nums[j] == target:
            print(i, j)
```


## 2. 백트래킹(재귀)

경우의 수를 탐색하다가 조건을 만족할 수 없는 경로를 즉시 되돌아간다. 완전 탐색에 **가지치기**를 더한 방식이다.

- 선택 → 재귀 호출 → 선택 취소 순서를 지킨다.
- 순열, 조합, N-Queen, 스도쿠 문제에 자주 사용한다.
- 같은 상태를 반복 계산한다면 백트래킹보단 DP를 의심한다.

```python
# 1부터 n까지 중 m개를 고르는 순열
used = [False] * (n + 1)
path = []

def backtrack():
    if len(path) == m:
        print(*path)
        return

    for x in range(1, n + 1):
        if used[x]:
            continue
        used[x] = True
        path.append(x)
        backtrack()
        path.pop()          # 선택 취소
        used[x] = False

backtrack()
```

가지치기는 재귀 호출 전에 넣는다.

```python
if not possible(next_state):
    continue
```

## 3. 그리디

매 순간 가장 좋아 보이는 선택을 하며 답을 만든다. 빠르지만, **지역 최적 선택이 전체 최적해를 보장하는 근거**가 있어야 한다.

- 정렬한 뒤 앞이나 뒤에서 선택하는 형태가 많다.
- 선택을 번복하지 않아도 되는지 확인한다.
- 반례가 하나라도 있으면 **그리디를 사용할 수 없다.**

```python
# 활동 선택: 종료 시간이 빠른 순서대로 선택
meetings.sort(key=lambda x: x[1])

count, end = 0, -float("inf")
for start, finish in meetings:
    if start >= end:
        count += 1
        end = finish
```

그리디 풀이를 떠올렸다면 바로 구현하기 전에 꼭! 이것이 최적해인지 생각해보자.

## 4. 다이나믹 프로그래밍(DP)

큰 문제의 답을 작은 문제의 답으로 만들고, 계산 결과를 저장해 중복 계산을 제거한다.

- 조건: **중복되는 부분 문제**, **최적 부분 구조**
- 가장 중요: `dp[i]`의 의미를 한 문장으로 정의하기
- 순서: 상태 정의 → 점화식 → 초기값 → 계산 순서 → 정답 위치

```python
# n번째 피보나치 수: O(N) 시간, O(N) 공간
dp = [0] * (n + 1)
if n >= 1:
    dp[1] = 1

for i in range(2, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]

print(dp[n])
```

직전 값만 필요하면 공간을 `O(1)`로 줄일 수 있다.

```python
a, b = 0, 1
for _ in range(n):
    a, b = b, a + b
print(a)
```

## 5. DFS

한 경로를 끝까지 탐색한 뒤 되돌아온다. 연결 요소, 경로 존재 여부, 사이클, 트리 순회 등에 사용한다.

- 인접 리스트 기준 시간복잡도: `O(V + E)`
- 재귀 또는 스택으로 구현한다.
- 재귀 DFS는 깊이가 크면 재귀 제한과 스택 오버플로를 주의한다.

```python
def dfs(v):
    visited[v] = True
    for nv in graph[v]:
        if not visited[nv]:
            dfs(nv)

visited = [False] * (n + 1)
dfs(1)
```

격자에서는 보통 다음 방향 배열을 사용한다.

```python
dx = (-1, 1, 0, 0)
dy = (0, 0, -1, 1)
```

> 백트래킹은 답 후보를 만들며 선택을 취소하고, DFS는 그래프의 정점·경로를 탐색한다. 구현은 비슷하지만 목적이 다르다.

## 6. BFS

시작점에서 가까운 정점부터 탐색한다. **가중치가 없는 그래프의 최단 거리**에 가장 자주 사용한다.

- 인접 리스트 기준 시간복잡도: `O(V + E)`
- 반드시 `collections.deque`를 사용한다.
- 큐에 넣을 때 방문 처리해야 중복 삽입을 막을 수 있다.

```python
def bfs(start):
    dist = [-1] * (n + 1)
    dist[start] = 0
    q = deque([start])

    while q:
        v = q.popleft()
        for nv in graph[v]:
            if dist[nv] == -1:
                dist[nv] = dist[v] + 1
                q.append(nv)

    return dist
```

간선 가중치가 모두 같을 때만 일반 BFS로 최단 거리를 구할 수 있다. 가중치가 다르면 다익스트라 등의 알고리즘을 사용한다.

## 7. 이분 탐색

정렬된 탐색 범위를 절반씩 줄인다. 배열 탐색뿐 아니라 “조건을 만족하는 최소·최대값”을 찾는 **매개변수 탐색**에도 사용한다.

- 시간복잡도: `O(log N)`
- 전제: 배열이 정렬되어 있거나, 판정 결과가 한 방향으로만 바뀌어야 한다.
- `bisect_left`: 값 이상이 처음 나오는 위치
- `bisect_right`: 값보다 큰 값이 처음 나오는 위치

```python
# 정렬된 배열에서 target의 개수
left = bisect_left(nums, target)
right = bisect_right(nums, target)
count = right - left
```

조건을 만족하는 최솟값을 찾는 기본 형태는 다음과 같다.

```python
lo, hi = 0, max_value

while lo < hi:
    mid = (lo + hi) // 2
    if possible(mid):
        hi = mid
    else:
        lo = mid + 1

print(lo)
```

무한 루프를 피하려면 구간의 의미를 먼저 정하고, 매 반복마다 탐색 구간이 반드시 줄어드는지 확인한다.

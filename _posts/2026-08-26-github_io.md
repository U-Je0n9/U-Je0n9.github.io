# GitHub Pages + Jekyll + Chirpy 블로그 만들기

GitHub Pages에 Jekyll과 Chirpy 테마를 적용해 개발 블로그를 만드는 과정을 정리한다.

## 1. GitHub Pages 저장소 만들기

GitHub에서 다음 이름으로 Repository를 생성한다.

```text
username.github.io
```

예:

```text
U-Je0n9.github.io
```

GitHub Pages 설정은 Repository의

```text
Settings → Pages
```

에서 확인한다.

Chirpy를 사용할 경우 Build and deployment의 Source는 다음으로 설정한다.

```text
GitHub Actions
```

---

## 2. 로컬에 Repository Clone

```bash
git clone https://github.com/username/username.github.io.git
cd username.github.io
```

---

## 3. Ruby, Jekyll, Bundler 설치

Jekyll은 Ruby 기반이므로 Ruby 환경이 필요하다.

Bundler 설치:

```bash
gem install bundler
```

Jekyll 설치:

```bash
gem install jekyll
```

설치 확인:

```bash
jekyll -v
bundle -v
```

---

## 4. Chirpy Starter 적용

Chirpy Starter를 임시 디렉터리에 clone한다.

```bash
git clone https://github.com/cotes2020/chirpy-starter.git /tmp/chirpy-starter
```

현재 Repository의 `.git` 폴더는 유지해야 한다.

기존 파일을 정리할 경우:

```bash
find . -mindepth 1 -maxdepth 1 ! -name '.git' -exec rm -rf {} +
```

그다음 Chirpy 파일만 복사한다.

```bash
rsync -av --exclude='.git' /tmp/chirpy-starter/ ./
```

> `.git`은 현재 Repository의 Git 연결 정보이므로 삭제하면 안 된다.

---

## 5. 의존성 설치

Chirpy 프로젝트 안에서 실행한다.

```bash
bundle install
```

---

## 6. 로컬 실행

```bash
bundle exec jekyll serve
```

정상적으로 실행되면 다음 주소에서 확인할 수 있다.

```text
http://127.0.0.1:4000
```

종료:

```text
Ctrl + C
```

---

## 7. 블로그 기본 정보 수정

`_config.yml`을 수정한다.

주로 수정할 항목:

```yaml
title:
tagline:
description:
url:
avatar:
```

예:

```yaml
title: "Yujeong's Blog"
tagline: "AI · Development · Study Notes"
description: >
  공부하고 개발하면서 배운 내용을 기록합니다.

url: "https://U-Je0n9.github.io"

avatar: /assets/img/profile.jpg
```

프로필 이미지는 예를 들어 다음 위치에 저장한다.

```text
assets/img/profile.jpg
```

`_config.yml`을 수정한 뒤 로컬에서 반영되지 않으면 서버를 재시작한다.

```bash
bundle exec jekyll serve
```

---

## 8. 게시글 작성

게시글은 `_posts` 폴더에 Markdown 파일로 작성한다.

파일명 형식:

```text
YYYY-MM-DD-title.md
```

예:

```text
_posts/2026-08-26-github-blog.md
```

기본 형식:

```yaml
---
title: "글 제목"
date: 2026-08-26 23:18:00 +0900
categories: [Development, Blog]
tags: [github, jekyll, chirpy]
---
```

그 아래부터 Markdown으로 작성한다.

```md
# 제목

내용

## 소제목

내용
```

---

## 9. 카테고리 나누기

Chirpy에서는 게시글의 `categories`로 카테고리를 지정한다.

예:

```yaml
categories: [Development, Docker]
```

```yaml
categories: [AI, LLM]
```

```yaml
categories: [Study, SQLD]
```

구조 예시:

```text
AI
├── LLM
└── NLP

Development
├── Docker
├── Database
└── Backend

Study
├── SQLD
└── 정보처리기사
```

`tags`는 더 세부적인 키워드에 사용한다.

```yaml
categories: [Development, Docker]
tags: [docker, container, image]
```

---

## 10. GitHub에 배포

수정이 끝나면:

```bash
git add .
git commit -m "Update blog"
git push
```

GitHub Actions가 자동으로 Jekyll 사이트를 빌드한 뒤 GitHub Pages에 배포한다.

배포 상태는 다음에서 확인한다.

```text
GitHub Repository → Actions
```

초록색 체크가 뜨면 배포 성공이다.

---

## 11. GitHub Pages가 바로 안 바뀌는 경우

Actions는 성공했는데 이전 화면이 보이면 브라우저 캐시를 확인한다.

Mac:

```text
Command + Shift + R
```

또는 시크릿 창에서 접속한다.

---

## 12. 다른 컴퓨터에서도 글 작성하기

다른 컴퓨터에서 로컬 미리보기가 필요 없다면 Ruby/Jekyll을 설치하지 않아도 된다.

필요한 것:

```text
Git
VS Code 등의 편집기
```

처음 한 번:

```bash
git clone https://github.com/username/username.github.io.git
cd username.github.io
```

작업 시작 전:

```bash
git pull
```

글 작성 후:

```bash
git add .
git commit -m "Add new post"
git push
```

GitHub Actions가 빌드와 배포를 대신 수행한다.

Ruby/Jekyll은 `localhost:4000`에서 미리보기할 때만 필요하다.

---

## 기본 작업 흐름

```text
git pull
   ↓
_posts에 Markdown 글 작성
   ↓
git add .
   ↓
git commit
   ↓
git push
   ↓
GitHub Actions
   ↓
GitHub Pages 배포
```
